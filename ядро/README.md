# ЯДРО

Мини-продукт: готовый цифровой продукт для экспертов и блогеров, собираемый ботом
из 15 минут ответов клиента. Часть воронки отдела — стоит между лид-магнитом
и основным продуктом.

## Файлы

- `offer.md` — офер: Godfather Offer, что внутри (продукт + 3 бонуса), механика,
  возражения, место в воронке, рекомендация по технической сборке (бот).
- `longread.md` — черновик продающей страницы по универсальному шаблону лонгрида,
  с реальным содержанием (разрыв «что» vs «как»), а не заполнением плейсхолдеров.
- `interview-questions.md` — 15 вопросов, которые бот задаёт клиенту; рабочий
  список для сборки промта/бота.

## Статус

Офер и лонгрид — черновики, готовы к правке под голос (`brand/voice.md` пока
пустой). Дедлайн/ограничение в лонгриде оставлено пустым сознательно — вписывать
только реальные условия запуска.
