# ЯДРО — 15 вопросов бота

Рабочий список для сборки бота/промта. Собраны по схеме «желания → решения,
страхи → возражения» из конструктора программы. Не для показа клиенту как список —
бот задаёт их по одному, без предисловий.

1. В какой нише ты работаешь и с кем — опиши коротко.
   *(зачем: язык и контекст всего продукта)*
2. Кто твой идеальный клиент одним предложением — статус, чем занят, о чём думает.
   *(зачем: адресность, «это для меня»)*
3. Какой один измеримый результат хочет получить этот клиент?
   *(зачем: конечная цель офера, по Хормози)*
4. Что клиент уже пробовал для этого результата — и почему не сработало?
   *(зачем: сырьё для усиления боли)*
5. Три главных страха или возражения клиента перед покупкой.
   *(зачем: блок закрытия возражений)*
6. За какой реалистичный срок клиент может дойти до результата с твоей помощью?
   *(зачем: timeframe офера)*
7. Чем твой подход отличается от того, что обычно предлагают в нише?
   *(зачем: уникальный механизм)*
8. Есть ли кейсы, цифры, опыт, которые это подтверждают? Если нет — что подтверждает
   экспертность иначе?
9. В каком формате тебе удобнее давать материал: видео, текст, чек-листы, скрипты?
   *(зачем: форма подачи модулей)*
10. Назови 3 главных шага/этапа своего метода — по одному на модуль.
    *(зачем: три модуля стартового продукта, правило «не больше трёх»)*
11. Для каждого шага — что человек получит конкретно (инструмент, а не тема).
    *(зачем: формула УСВ для подмодулей)*
12. Какую гарантию ты готова дать — деньги назад, условная, без гарантии?
13. На какую цену ориентируешься для этого продукта?
14. Что ты сознательно НЕ обещаешь — где граница честности?
    *(зачем: чтобы офер не свалился в «неотразимо, но недостижимо»)*
15. Кодовое слово или название, с которым продукт должен ассоциироваться с тобой.
