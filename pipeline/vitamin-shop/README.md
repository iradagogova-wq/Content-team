Материалы конкретного клиентского проекта — не общая ниша отдела. Загружены
26.08.2026, чтобы не держать их только в переписке (правило 6 в `CLAUDE.md`).

| Файл | Что внутри | Статус |
| ---- | ---------- | ------ |
| `бриф.md` | Анкета из 55 вопросов (короткая версия — 15) | Без ответов — если проходили устно, занести ответы отдельным разделом |
| `стратегия.md` | Полная стратегия продвижения: 5 направлений контента, воронка, лид-магнит, безопасный язык, KPI | Рабочая версия |
| `рилс-10-готово.md` | 10 готовых Reels, код-слово «ВИТА» | Готово, воспроизведено дословно |
| `карусели-10-готово.md` | 10 готовых каруселей по дням, у каждой своё код-слово и фактчекинг | Готово, воспроизведено дословно |

Новые темы для этого проекта берутся отсюда — сверяются с тем, что уже
закрыто в двух готовых контент-планах, чтобы не повторяться — а не из
общей карты ниши в `research/` (её для витаминов нет).

Правила проекта, которые нельзя нарушать в новых сценариях (из
`стратегия.md` §4 и §9): спикер не изображает врача и не говорит от лица
хозяйки; никаких «лечит», «нужен всем», «гарантированно»; доверие строится
через то, что показывает сам магазин, а не через нападки на маркетплейсы;
медицински чувствительные темы (железо, беременность, дети, высокие
дозировки) — на проверку специалисту перед публикацией.
