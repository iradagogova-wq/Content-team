# Карусель: «Витамины пьёшь месяцами. Толку — ноль?»

## Шапка

| Поле | Значение |
| ---- | -------- |
| Тема | 4 ошибки приёма витаминов, из-за которых их эффект «не чувствуется» |
| Формат | карусель |
| **Режим** | **А — лид-магнит** |
| Площадка | Instagram (пересылается и в Telegram) |
| Для кого | покупатели витаминов, которые пропили курс и не заметили разницы |
| Боль | «купила банку, пила честно — толку ноль», ощущение, что деньги на ветер |
| Что зритель сделает после | напишет кодовое слово в комментариях |
| Лид-магнит и кодовое слово | персональный разбор «что пить именно тебе, когда и с чем» → слово **ПОДБОР** *(рабочий вариант — замени на своё, если в аккаунте уже есть кодовое слово)* |
| Длина | 8 слайдов |
| Источник темы | **карты ниши в `research/` для витаминов нет** — в отделе разобрана только ниша «маркетинг для экспертов» (см. `research/ЧТО-МЫ-ЗНАЕМ.md`). Карусель построена на универсальных рычагах из `brand/psychology.md`, а не на анализе конкретных вирусных постов этой ниши. Перед серийным выпуском рекомендуется прогнать `/niche витамины` — так хуки будут калиброваны по тому, что реально залетает именно здесь. |

**Факты о приёме витаминов ниже — общеизвестная нутрициологическая логика (жирорастворимые витамины и жир, кальций и железо конкурируют за всасывание), без конкретных процентов, сроков и исследований.** Цифр, кейсов и отзывов магазина в тексте нет — их брать неоткуда, выдумывать нельзя.

**Обложка:** «Витамины пьёшь месяцами. Толку — ноль?» — баночка витаминов крупным планом в руке, размытый растерянный взгляд на фоне.

**Подпись под пост:**
Считается, что с витаминами всё просто: купил — выпил — готово.
На деле большинство банок в ванной пьют неправильно — и потом решают, что «организму просто не подошло».
Дело не в организме. Дело в порядке приёма.
Напиши ПОДБОР в комментариях — разберём, что пить тебе, когда и с чем, чтобы это вообще работало.

**Что сохранят:** список из 4 ошибок — чтобы свериться перед следующей покупкой витаминов.

### 2. Четыре вопроса

1. **Зачем досматривать?** Считается до конца: 4 ошибки, номер виден на каждом слайде — неудобно уйти на второй.
2. **Зачем сохранять?** Названо вслух на слайде 8: пригодится перед следующей покупкой.
3. **Зачем пересылать?** Подпись даёт цитируемую мысль про «банки в ванной, которые пьют неправильно» — узнавание, лёгкое раздражение на систему, а не на себя.
4. **Что человек сделает после?** Напишет «ПОДБОР» в комментариях.
