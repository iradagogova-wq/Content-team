# ИИ-сериал «Эль Вита» · S01E02 «Двадцать секунд»

Клиентский проект: магазин витаминов **El Vita**. Вторая серия сезона, формат — рилс.
Производственные файлы в студии `-claude-workspace`: `episodes/S01E02.md` (раскадровка),
`characters/tik.md` (Locked prompt block антагониста).

---

## Шапка

| Поле | Значение |
| ---- | -------- |
| Тема | человеку предлагают сделать его дело быстрым и прибыльным — и он отказывается, потому что тогда дело перестанет быть его |
| Формат | ИИ-мультфильм · серия 2 сезона · рилс |
| **Режим** | **Б — нативная продажа** |
| Площадка | `ЗАПОЛНИТЬ` — Reels / Shorts / TikTok / ВК. Раскадровка под вертикаль 9:16 |
| Для кого | 25–45, город. Плюс те, кто сам что-то делает руками и кому предлагали «масштабировать» |
| Боль | «если я сделаю как все советуют, это перестанет быть моим» |
| Что зритель сделает после | процитирует финальную фразу и вернётся за третьей серией |
| Лид-магнит и кодовое слово | нет — режим Б |
| Длина | 40 секунд · 8 кадров по 5 секунд · зациклено |
| **Источник темы** | **`ЗАПОЛНИТЬ`** — карты ниши «витамины и БАД» в `research/` по-прежнему нет. Тема выведена из арки сезона, а не из разбора. `/niche витамины и БАД` до запуска сезона |

## Сценарий по кадрам

| Кадр | Сек | Что происходит | План | Камера | Реплика |
| ---- | --- | -------------- | ---- | ------ | ------- |
| 2.01 | 0–5 | Лавка изнутри, дверь в глубине. Колокольчик. Все тёплые лампы разом тускнеют на треть, растения под потолком поджимают листья. В кадр ложится длинная холодная тень | общий | slow push in | — |
| 2.02 | 5–10 | Рука на тёплом деревянном прилавке, циановые часы — единственная холодная точка. Пальцы один раз постукивают | крупный, деталь | static shot, character moves | **ТИК** (за кадром): «У вас красиво» |
| 2.03 | 10–15 | Тик целиком, первое появление лица за сериал. Безупречный серый костюм, безупречная улыбка | средний, нижняя точка | low angle hero shot | **ТИК**: «Я не за лавкой» |
| 2.04 | 15–20 | Вита за прилавком, не поднимает глаз, переставляет банки | средний | static shot, character moves | **ВИТА**: «Знаю» |
| 2.05 | 20–25 | Он ставит на прилавок банку с её же полки и накрывает ладонью. Свет часов проходит сквозь пальцы, стекло изнутри наливается циановым | крупный | slow push in | **ТИК**: «Через месяц она будет работать за двадцать секунд. Вывеска остаётся ваша» |
| 2.06 | 25–30 | Вита впервые за сериал поднимает глаза. Долгий взгляд. И улыбается | крупный | slow push in | **ВИТА**: «И чья это будет лавка?» |
| 2.07 | 30–35 | Забирает банку из-под его ладони. Циан вытекает из стекла. Ставит обратно на полку — не на прилавок | средний | gentle pan left | **ТИК** (уходя, ровно): «Конечно» |
| 2.08 | 35–40 | На прилавке серое пятно размером с ладонь, рука Виты ложится рядом — не отогревается. Отъезд: лавка, закрытая дверь, одна лампа над дверью не горит | средний → шире | slow pull out | — |

**25 слов на 40 секунд.** Переговоры выигрывает тот, кто говорит меньше.

**Вся серия на восьмёрке.** Двое не оказываются в одном кадре ни разу: 2.02, 2.03,
2.05 — Тик, 2.04, 2.06, 2.07 — Вита. Модели ломают лица в двойных портретах, а здесь
приём ещё и работает на смысл: они не в одном кадре, потому что не в одном мире.

**Тиканье — голос Тика.** Появляется с ним, ускоряется на предложении, обрывается на
её вопросе и больше не возвращается. Дешевле музыки и работает сильнее.

## Что делает серию форматной для рилс

| Приём | Как сделано |
| ----- | ----------- |
| Зацикливание | 2.01 открывается на двери, 2.08 отъездом возвращает дверь. Ролик склеивается сам с собой — второй просмотр бесплатно, площадка засчитывает досмотр |
| Смотрят без звука | все 25 слов идут субтитрами, серия читается картинкой целиком |
| Хук без контекста | не смотревший первую серию всё равно понимает 2.01: вошёл человек — и похолодало |
| Обложка ленты | кадр 2.05, чужая рука на её банке, циан сквозь пальцы |
| Первые 3 секунды | без заставки и названия. Сразу событие |

## Проверка по рычагам

Прогнано по `brand/psychology.md`, раздел 6, вручную в этой сессии.

| Блок | Рычаг | Как работает |
| ---- | ----- | ------------ |
| Хук | про меня · слом ожидания | «вошёл человек, и в комнате похолодало» узнают все, сериал для этого не нужен |
| Обещание | разрыв в знании | «Я не за лавкой» — а за чем? |
| Тело | конкретика · точка отсчёта | «двадцать секунд», «через месяц» — шкалу задаёт он, и это его сила |
| Поворот | честная оговорка · пик | предложение выгодное и без подвоха. Отказ от хорошего сильнее отказа от плохого |
| Финал | пик и финал | серое пятно, которое не отогревается. Образ вместо титра |
| Почему перешлют | фраза для цитирования | «И чья это будет лавка?» уносится в разговор про работу и партнёрство |

**Где серия слабее пилота — честно.** Пилот был про боль зрителя, эта серия про
бренд: зритель в ней не участвует, он наблюдает. Отрабатывается только фразой из
2.06. **Если досматриваемость просядет ниже пилота — в серии 3 возвращаться к гостю
недели и чужой боли, а Тика держать фоном до серии 5.** Это заранее прописанный
план отхода, а не оправдание задним числом.

**Второй риск: разговорная серия без действия.** Восемь кадров, из них семь почти
статичных. Держит её только звук и монтажный ритм — если озвучку сделать наспех,
серия рассыплется.

## Что серия делает для магазина

Ни продажи, ни призыва, слова «витамины» нет.

- **Позиционирование разыграно, а не заявлено.** Магазину предложили сделать быстро,
  и магазин отказался — при том что предложение было хорошим.
- **Банка снова не открывается** — правило сезона держится.
- **Никаких свойств, эффектов и сроков действия** не названо. Единственные числа —
  «двадцать секунд» и «через месяц», оба про предложение Тика, а не про товар.

Правовой контур — те же три поля `ЗАПОЛНИТЬ`, что в пилоте (ФЗ «О рекламе» № 38-ФЗ,
ст. 25): что продаёт магазин, формулировка предупреждения, ERID.
