# 3 карусели на сохранение и репост — для женской аудитории

> По запросу: **без опоры на загруженный контент-план** (`pipeline/vitamin-shop/`).
> Все три темы — новые, ни одна не повторяет ни одну из 10 готовых
> каруселей клиента и ни одну из 5 идей, предложенных ранее в этом чате.
> **Версия 2 — сжато до 6–7 слайдов, строго один слайд = одна мысль**
> (в версии 1 было 8–9; лишние слайды со смежными мыслями объединены или
> сокращены, а не просто вырезаны — тест на «5 фраз» стал тестом на 3, а не
> тестом с двумя фразами на одном слайде).
>
> Угол сознательно смещён с «симптом → нутриент» (по этой схеме построены
> все 10 готовых каруселей) на **идентичность и поведение**: как женщина
> сама себя ставит последней в списке заботы. Это даёт два разных мотива
> одновременно — по `brand/psychology.md` §5: **сохраняют** ради пользы
> себе, **пересылают** ради того, что это говорит о тебе другим (узнавание,
> «это про нас», желание отметить подругу).
>
> Код-слова новые, не пересекаются с уже занятыми (ВИТА, МАГНИЙ, ВИТАМИН D,
> ВОЛОСЫ, ДЕТИ, АППЕТИТ, КРАСОТА, ЖЕЛЕЗО, ПЛАНИРОВАНИЕ, РАЗБОР, МУЖЧИНА,
> ФОРМА, РЕВИЗИЯ, ПРОВЕРКА, ИНОЗИТОЛ).
>
> Формулировки проверены по безопасному языку клиента (`стратегия.md` §9.3):
> нет «лечит», «нужен всем», «гарантированно», нет диагноза по симптому.

## Карусель 1. «В вашей аптечке нет вас»

| Поле | Значение |
| ---- | -------- |
| Тема | Женщина ведёт здоровье всей семьи и почти никогда — своё |
| Формат | карусель |
| **Режим** | **А — лид-магнит** |
| Для кого | женщины, которые следят за витаминами мужа и детей |
| Боль | забота о себе — последним пунктом списка, годами; вина при мысли купить что-то себе |
| Что зритель сделает после | сохранит, отметит подругу в комментариях, напишет кодовое слово |
| Код-слово | **ЗАБОТА** — персональный разбор «что нужно именно вам», без семейного списка |
| Длина | 7 слайдов |

| Слайд | Текст на слайде | Что на картинке | Зачем он тут |
| ----- | --------------- | --------------- | ------------ |
| 1 | В вашей аптечке нет вас | крупный план органайзера для таблеток: отсеки подписаны «Ребёнку», «Мужу» — один пустой, без подписи | хук — слом ожидания, узнавание |
| 2 | Витамины мужу — купила. Витамины детям — на столе. Свои — «потом, сейчас не до этого». | стол с двумя расставленными баночками с именными стикерами и пустым местом рядом | про тебя — боль словами читателя |
| 3 | Вы помните дозировку детского витамина D наизусть. А когда в последний раз пили что-то своё регулярно — не вспомните. | рука листает заметки в телефоне: есть дата последнего приёма у ребёнка, поиск по своему имени — пусто | тело — контраст, одна мысль |
| 4 | Это не забывчивость. Это порядок, в котором себя ставят последней — годами. Меняется он с одной привычки: сначала себе, потом остальным. | календарь на стене: дни всех членов семьи отмечены цветом, «свой» цвет почти не встречается | тело — называет паттерн и точку выхода |
| 5 | Простое правило: банка для вас — на виду. Не в дальнем углу шкафа, за баночками для всех остальных. | рука переставляет баночку на передний план полки, ближе к дверце | тело — практический шаг |
| 6 | Это не про «купите витамины — и всё наладится». Это про то, что вы вообще имеете право быть в этом списке. | рука держит телефон с сообщением самой себе: «начни с себя» | поворот — честная оговорка |
| 7 | Сохрани — это напоминание себе, а не подруге. Хочешь разобраться, что нужно именно тебе? Напиши ЗАБОТА — без списка «для всех». | экран телефона, в комментариях набрано «ЗАБОТА» | финал, призыв и причина сохранить |

**Обложка:** «В вашей аптечке нет вас» — органайзер для таблеток крупным планом, пустой безымянный отсек.

**Подпись под пост:**
Мы знаем дозировку чужого лекарства наизусть и путаемся в своей.
Это не про лень. Это про порядок в списке, который никто не проверял вслух.
Отметьте в комментариях подругу, которая тоже всегда «на потом» — а если хотите начать с себя, напишите ЗАБОТА.

**Что сохранят:** напоминание — не забывать себя в собственном списке.

### Разбор Психолога

| Блок | Рычаг | Сила |
| ---- | ----- | ---- |
| Хук | слом ожидания, про меня | сильно |
| Про тебя | про меня, конкретика | сильно |
| Тело | лестница микро-да, конкретика, лёгкость чтения | сильно |
| Поворот | честная оговорка | сильно |
| Финал | практическая польза названа вслух, одно действие | сильно |
| Подпись | социальная валюта («отметьте подругу» — прямой репост-триггер) | сильно |

1. **Зачем досматривать?** Каждый слайд называет то, что читатель узнаёт в себе.
2. **Зачем сохранять?** Названо вслух на слайде 7: напоминание себе, а не разовая польза.
3. **Зачем пересылать?** Подпись прямо просит отметить конкретную подругу.
4. **Что человек сделает после?** Отметит подругу и/или напишет «ЗАБОТА».

**Вердикт: сдавать.** Пустых блоков нет, слайд 4 держит две мысли в одной формулировке (диагноз + выход), но подан как единый вывод, а не два раздельных утверждения — не дробит внимание. Красных линий нет.

## Карусель 2. «Шкаф из недопитых банок»

| Поле | Значение |
| ---- | -------- |
| Тема | Импульсивные покупки витаминов «на всякий случай», которые потом не допиваются |
| Формат | карусель |
| **Режим** | **А — лид-магнит** |
| Для кого | женщины, которые покупают под влиянием момента, рекламы, совета блогера |
| Боль | раздражение на себя за потраченные деньги; шкаф, полный начатых банок |
| Что зритель сделает после | сохранит, напишет кодовое слово |
| Код-слово | **ШКАФ** — разбор того, что уже куплено, без новой банки «на всякий случай» |
| Длина | 7 слайдов |

| Слайд | Текст на слайде | Что на картинке | Зачем он тут |
| ----- | --------------- | --------------- | ------------ |
| 1 | Откройте свой шкаф с витаминами | открытая дверца полки с 5–6 начатыми банками разного вида | хук — прямое действие вместо вопроса |
| 2 | Там наверняка есть банка, начатая в январе. И вторая — «увидела у блогера». Обе почти полные. | крупный план банки, на этикетке видно, что куплена давно и почти не тронута | про тебя — конкретика, узнавание |
| 3 | Это не значит, что вы плохо заботитесь о себе. Это значит, что покупка случилась раньше решения. | рядом с банкой — открытый на телефоне пост блогера с рекомендацией | тело — снимает вину |
| 4 | Обычно так: увидели совет → купили → забыли → купили снова, «эта точно поможет». Каждая новая банка на фоне непрочитанной старой — это тревога, которую заедаете покупкой. | рука выставляет в ряд несколько начатых банок одну за другой | тело — цепочка как одна мысль |
| 5 | Перед следующей покупкой: откройте шкаф. Три банки «может, поможет» — сигнал, что нужен не новый совет, а разбор того, что уже есть. | рука открывает дверцу шкафа перед тем, как взять телефон | тело — практический шаг |
| 6 | Мы тоже продаём витамины. И всё равно говорим: не все банки в шкафу нужно было покупать. Это дороже, чем кажется. | спикер магазина честно рассматривает баночку — нейтральный, не продающий кадр | поворот — честная оговорка от продавца |
| 7 | Сохрани — пригодится в следующий раз, когда захочется купить «на всякий случай». Напиши ШКАФ — поможем без лишней банки. | экран телефона, в комментариях набрано «ШКАФ» | финал, призыв и причина сохранить |

**Обложка:** «Откройте свой шкаф с витаминами» — открытая полка с начатыми банками.

**Подпись под пост:**
Мы могли бы посчитать, сколько в среднем стоит такой шкаф — но цифра тут не главное.
Главное — узнавание: почти у каждой из нас есть эта полка.
Сохраните, пока не купили следующую банку «на всякий случай». И напишите ШКАФ, если хотите один раз разобраться, а не гадать в пятый.

**Что сохранят:** чтобы вспомнить об этом в магазине — перед новой импульсивной покупкой.

### Разбор Психолога

| Блок | Рычаг | Сила |
| ---- | ----- | ---- |
| Хук | слом ожидания (действие, а не вопрос) | сильно |
| Про тебя | конкретика, узнавание | сильно |
| Тело | лестница микро-да, честная оговорка встроена рано | сильно |
| Поворот | честная оговорка от лица магазина | сильно |
| Финал | одно действие, практическая польза | сильно |
| Подпись | явный отказ от выдуманной цифры («цифра тут не главное») | сильно |

1. **Зачем досматривать?** Слайд 4 идёт по нарастанию паттерна одним ударом — читатель узнаёт всю цепочку сразу.
2. **Зачем сохранять?** Названо вслух: пригодится в момент следующей покупки.
3. **Зачем пересылать?** Подпись называет общее узнавание («почти у каждой из нас»).
4. **Что человек сделает после?** Откроет свой шкаф и/или напишет «ШКАФ».

**Вердикт: сдавать.** Слайд 7 у магазина, признающего лишние покупки клиентов — редкий и сильный ход для доверия. Красных линий нет.

## Карусель 3. «Три фразы. Все — про вас?»

| Поле | Значение |
| ---- | -------- |
| Тема | Самоузнавание через 3 типичные фразы-отговорки от заботы о себе |
| Формат | карусель (формат-тест, не история) |
| **Режим** | **А — лид-магнит** |
| Для кого | женщины, откладывающие заботу о себе на «потом» |
| Боль | хроническое «начну с понедельника»; в списке дел себя нет |
| Что зритель сделает после | сохранит, отправит подруге, напишет кодовое слово |
| Код-слово | **ТЕСТ** — с чего начать сегодня, без общего совета |
| Длина | 7 слайдов |

| Слайд | Текст на слайде | Что на картинке | Зачем он тут |
| ----- | --------------- | --------------- | ------------ |
| 1 | Три фразы. Все — про вас? | телефон, на экране открыты заметки с крупным заголовком «Тест» | хук — виден край, любопытство |
| 2 | Не тест на знания. Тест на то, сколько раз в неделю вы откладываете себя на «потом». | рука держит телефон, палец готов листать дальше | про тебя — снижает порог входа |
| 3 | Фраза 1 из 3: «Начну заботиться о себе с понедельника». | рука пишет эту фразу в заметках на телефоне | тело — виден край 1/3 |
| 4 | Фраза 2 из 3: «Сначала разберусь со всеми, потом с собой». | тот же приём, следующая фраза на экране | тело — виден край 2/3 |
| 5 | Фраза 3 из 3: «Это же мелочь, потерплю». | тот же приём | тело — виден край 3/3 |
| 6 | Если узнали себя хотя бы в одной — это не лень и не слабость. Это порядок, в котором вы привыкли о себе не думать. | рука откладывает телефон в сторону, пауза | поворот — честная оговорка, снимает стыд |
| 7 | Сохрани — присылай себе, когда снова скажешь одну из этих фраз. Готова начать не с понедельника, а сегодня? Напиши ТЕСТ. | экран телефона, в комментариях набрано «ТЕСТ» | финал, призыв и причина сохранить |

**Обложка:** «Три фразы. Все — про вас?» — телефон с заголовком «Тест» на экране заметок.

**Подпись под пост:**
Три фразы — простой тест, а не диагноз.
Если узнали себя хотя бы в одной — это, скорее всего, не про вас лично, а про то, как вообще устроен день у большинства женщин рядом с вами.
Отправьте это той, кто точно скажет «это про меня». А если готовы начать сегодня — напишите ТЕСТ.

**Что сохранят:** чтобы прислать себе в момент, когда снова скажете одну из этих фраз.

### Разбор Психолога

| Блок | Рычаг | Сила |
| ---- | ----- | ---- |
| Хук | разрыв в знании, виден край | сильно |
| Про тебя | снимает порог, объясняет правила теста | сильно |
| Тело (3 фразы) | виден край, лёгкость чтения, узнавание | сильно |
| Поворот | честная оговорка — снимает стыд после теста | сильно |
| Финал | практическая польза, одно действие | сильно |
| Подпись | прямой репост-механизм («отправьте той, кто скажет „это про меня“») | сильно |

1. **Зачем досматривать?** Формат теста с номерами 1/3…3/3 физически тянет долистать до конца.
2. **Зачем сохранять?** Названо вслух: личное напоминание на момент рецидива.
3. **Зачем пересылать?** Прямой призыв переслать конкретному человеку, который узнает себя.
4. **Что человек сделает после?** Перешлёт карусель и/или напишет «ТЕСТ».

**Вердикт: сдавать.** Три фразы вместо пяти держат карусель в 7 слайдов без потери формата-теста — каждая всё ещё отдельный слайд, отдельная мысль.
