# 3 карусели на сохранение и репост — для женской аудитории

> По запросу: **без опоры на загруженный контент-план** (`pipeline/vitamin-shop/`).
> Все три темы — новые, ни одна не повторяет ни одну из 10 готовых
> каруселей клиента и ни одну из 5 идей, предложенных ранее в этом чате.
>
> Угол сознательно смещён с «симптом → нутриент» (по этой схеме построены
> все 10 готовых каруселей) на **идентичность и поведение**: как женщина
> сама себя ставит последней в списке заботы. Это даёт два разных мотива
> одновременно — по `brand/psychology.md` §5: **сохраняют** ради пользы
> себе, **пересылают** ради того, что это говорит о тебе другим (узнавание,
> «это про нас», желание отметить подругу). Одна тема — один из двух
> мотивов слабее почти всегда; здесь в каждой карусели явно есть оба.
>
> Код-слова новые, не пересекаются с уже занятыми (ВИТА, МАГНИЙ, ВИТАМИН D,
> ВОЛОСЫ, ДЕТИ, АППЕТИТ, КРАСОТА, ЖЕЛЕЗО, ПЛАНИРОВАНИЕ, РАЗБОР, МУЖЧИНА,
> ФОРМА, РЕВИЗИЯ, ПРОВЕРКА, ИНОЗИТОЛ).
>
> Формулировки проверены по безопасному языку клиента (`стратегия.md` §9.3):
> нет «лечит», «нужен всем», «гарантированно», нет диагноза по симптому
> («у вас дефицит, потому что устали») — все три карусели про поведение и
> привычки, не про медицинские причины usталости.

## Карусель 1. «В вашей аптечке нет вас»

| Поле | Значение |
| ---- | -------- |
| Тема | Женщина ведёт здоровье всей семьи и почти никогда — своё |
| Формат | карусель |
| **Режим** | **А — лид-магнит** |
| Для кого | женщины, которые следят за витаминами мужа и детей |
| Боль | забота о себе — последним пунктом списка, годами; вина при мысли купить что-то себе |
| Что зритель сделает после | сохранит, отметит подругу в комментариях, напишет кодовое слово |
| Код-слово | **ЗАБОТА** — персональный разбор «что нужно именно вам», без семейного списка |
| Длина | 8 слайдов |

| Слайд | Текст на слайде | Что на картинке | Зачем он тут |
| ----- | --------------- | --------------- | ------------ |
| 1 | В вашей аптечке нет вас | крупный план органайзера для таблеток: отсеки подписаны «Ребёнку», «Мужу» — один отсек пустой, без подписи | хук — слом ожидания, узнавание |
| 2 | Витамины мужу — купила. Витамины детям — на столе. Свои — «потом, сейчас не до этого». | стол с двумя расставленными баночками с именными стикерами и пустым местом рядом | про тебя — боль словами читателя |
| 3 | Вы помните дозировку детского витамина D наизусть. А когда в последний раз пили что-то своё регулярно — не вспомните. | рука листает заметки в телефоне: есть дата последнего приёма у ребёнка, поиск по своему имени — пусто | тело — конкретика |
| 4 | Это не забывчивость. Это порядок, в котором женщина ставит себя последней — каждый день, годами. | календарь на стене: дни всех членов семьи отмечены цветом, «свой» цвет почти не встречается | тело — называет паттерн вслух |
| 5 | Это не чинится одной покупкой. Но начинается с одной привычки: сначала — себе, потом — остальным. | рука отодвигает баночки семьи, чтобы поставить одну свою вперёд | тело — переход к действию |
| 6 | Простое правило: банка для вас — на виду. Не в дальнем углу шкафа, за баночками для всех остальных. | баночка переставлена на передний план полки, ближе к дверце | тело — практический шаг |
| 7 | Это не про «купите витамины — и всё наладится». Это про то, что вы вообще имеете право быть в этом списке. | рука держит телефон с сообщением самой себе: «начни с себя» | поворот — честная оговорка |
| 8 | Сохрани — это напоминание себе, а не подруге. Хочешь разобраться, что нужно именно тебе? Напиши ЗАБОТА — без списка «для всех». | экран телефона, в комментариях набрано «ЗАБОТА» | финал, призыв и причина сохранить |

**Обложка:** «В вашей аптечке нет вас» — органайзер для таблеток крупным планом, пустой безымянный отсек.

**Подпись под пост:**
Мы знаем дозировку чужого лекарства наизусть и путаемся в своей.
Это не про лень. Это про порядок в списке, который никто не проверял вслух.
Отметьте в комментариях подругу, которая тоже всегда «на потом» — а если хотите начать с себя, напишите ЗАБОТА.

**Что сохранят:** напоминание — не забывать себя в собственном списке.

### Разбор Психолога

| Блок | Рычаг | Сила |
| ---- | ----- | ---- |
| Хук | слом ожидания, про меня | сильно |
| Про тебя | про меня, конкретика | сильно |
| Тело | лестница микро-да, конкретика, лёгкость чтения | сильно |
| Поворот | честная оговорка | сильно |
| Финал | практическая польза названа вслух, одно действие | сильно |
| Подпись | социальная валюта («отметьте подругу» — прямой репост-триггер) | сильно |

1. **Зачем досматривать?** Каждый слайд называет то, что читатель узнаёт в себе — уйти, не долистав «свою историю», неудобно.
2. **Зачем сохранять?** Названо вслух на слайде 8: это напоминание себе, а не разовая польза.
3. **Зачем пересылать?** Подпись прямо просит отметить конкретную подругу — узнавание плюс лёгкая забота о ней, не про магазин.
4. **Что человек сделает после?** Отметит подругу и/или напишет «ЗАБОТА».

**Вердикт: сдавать.** Пустых блоков нет, обещание из хука отработано, призыв один, красных линий (выдуманный дефицит, давление на стыд, страх без выхода) нет — вина называется как общий паттерн, а не как личная вина читателя.

## Карусель 2. «Шкаф из недопитых банок»

| Поле | Значение |
| ---- | -------- |
| Тема | Импульсивные покупки витаминов «на всякий случай», которые потом не допиваются |
| Формат | карусель |
| **Режим** | **А — лид-магнит** |
| Для кого | женщины, которые покупают под влиянием момента, рекламы, совета блогера |
| Боль | раздражение на себя за потраченные деньги; шкаф, полный начатых банок |
| Что зритель сделает после | сохранит, напишет кодовое слово |
| Код-слово | **ШКАФ** — разбор того, что уже куплено, без новой банки «на всякий случай» |
| Длина | 8 слайдов |

| Слайд | Текст на слайде | Что на картинке | Зачем он тут |
| ----- | --------------- | --------------- | ------------ |
| 1 | Откройте свой шкаф с витаминами | открытая дверца полки с 5–6 начатыми банками разного вида | хук — прямое действие вместо вопроса, необычный заход |
| 2 | Там наверняка есть банка, начатая в январе. И вторая — «увидела у блогера». Обе почти полные. | крупный план банки, на этикетке видно, что куплена давно и почти не тронута | про тебя — конкретика, узнавание |
| 3 | Это не значит, что вы плохо заботитесь о себе. Это значит, что покупка случилась раньше решения. | рядом с банкой — открытый на телефоне пост блогера с рекомендацией | тело — снимает вину |
| 4 | Обычно так: увидели совет → купили сразу → начали пить → забыли → купили следующую, «эта точно поможет». | рука выставляет в ряд несколько начатых банок одну за другой | тело — лестница микро-да |
| 5 | Каждая новая банка на фоне непрочитанной старой — это не забота о здоровье. Это тревога, которую заедаете покупкой. | крупный план: две почти полные банки стоят рядом, будто «ждут своей очереди» | тело — называет паттерн честно |
| 6 | Перед следующей покупкой: откройте шкаф. Три банки «может, поможет» — сигнал, что нужен не новый совет, а разбор того, что уже есть. | рука открывает дверцу шкафа перед тем, как взять телефон | тело — практический шаг |
| 7 | Мы тоже продаём витамины. И всё равно говорим: не все банки в шкафу нужно было покупать. Это дороже, чем кажется. | спикер магазина честно рассматривает баночку — нейтральный, не продающий кадр | поворот — честная оговорка от самого продавца |
| 8 | Сохрани — пригодится в следующий раз, когда захочется купить «на всякий случай». Напиши ШКАФ — поможем без лишней банки. | экран телефона, в комментариях набрано «ШКАФ» | финал, призыв и причина сохранить |

**Обложка:** «Откройте свой шкаф с витаминами» — открытая полка с начатыми банками.

**Подпись под пост:**
Мы могли бы посчитать, сколько в среднем стоит такой шкаф — но цифра тут не главное.
Главное — узнавание: почти у каждой из нас есть эта полка.
Сохраните, пока не купили следующую банку «на всякий случай». И напишите ШКАФ, если хотите один раз разобраться, а не гадать в пятый.

**Что сохранят:** чтобы вспомнить об этом в магазине — перед новой импульсивной покупкой.

### Разбор Психолога

| Блок | Рычаг | Сила |
| ---- | ----- | ---- |
| Хук | слом ожидания (действие, а не вопрос) | сильно |
| Про тебя | конкретика, узнавание | сильно |
| Тело | лестница микро-да, честная оговорка встроена рано | сильно |
| Поворот | честная оговорка от лица магазина — сильный рычаг доверия | сильно |
| Финал | одно действие, практическая польза | сильно |
| Подпись | лёгкость чтения, явный отказ от выдуманной цифры («цифра тут не главное») | сильно |

1. **Зачем досматривать?** Слайды 3–5 идут по нарастанию паттерна (совет → покупка → забыли → купили снова) — читатель хочет увидеть, чем кончится.
2. **Зачем сохранять?** Названо вслух: пригодится в момент следующей покупки.
3. **Зачем пересылать?** Подпись прямо называет общее узнавание («почти у каждой из нас») — раздражение на систему потребления, а не на себя, хорошо разносится.
4. **Что человек сделает после?** Откроет свой шкаф и/или напишет «ШКАФ».

**Вердикт: сдавать.** Слайд 7 — редкий и сильный ход (магазин признаёт лишние покупки клиентов) — усиливает доверие, а не подрывает продажи, потому что ведёт прямо к консультации. Красных линий нет.

## Карусель 3. «Тест: сколько из этих 5 фраз — про вас»

| Поле | Значение |
| ---- | -------- |
| Тема | Самоузнавание через 5 типичных фраз-отговорок от заботы о себе |
| Формат | карусель (формат-тест, не история) |
| **Режим** | **А — лид-магнит** |
| Для кого | женщины, откладывающие заботу о себе на «потом» |
| Боль | хроническое «начну с понедельника»; в списке дел себя нет |
| Что зритель сделает после | сохранит, отправит подруге, напишет кодовое слово |
| Код-слово | **ТЕСТ** — с чего начать сегодня, без общего совета |
| Длина | 9 слайдов (тест из 5 пунктов немного длиннее обычного тела) |

| Слайд | Текст на слайде | Что на картинке | Зачем он тут |
| ----- | --------------- | --------------- | ------------ |
| 1 | Пять фраз. Сколько — про вас? | телефон, на экране открыты заметки с крупным заголовком «Тест» | хук — виден край, любопытство |
| 2 | Не тест на знания. Тест на то, сколько раз в неделю вы откладываете себя на «потом». | рука держит телефон, палец готов листать дальше | про тебя — снижает порог, объясняет формат |
| 3 | Фраза 1 из 5: «Начну с понедельника». | рука пишет эту фразу в заметках на телефоне | тело — виден край 1/5 |
| 4 | Фраза 2 из 5: «Сначала разберусь со всеми, потом с собой». | тот же приём, следующая фраза на экране | тело — виден край 2/5 |
| 5 | Фраза 3 из 5: «Куплю себе — но не сейчас, сейчас не время». | тот же приём | тело — виден край 3/5 |
| 6 | Фраза 4 из 5: «Ничего, посплю в выходные». | тот же приём | тело — виден край 4/5 |
| 7 | Фраза 5 из 5: «Это же мелочь, потерплю». | тот же приём | тело — виден край 5/5 |
| 8 | Если узнали себя хотя бы в трёх — это не лень и не слабость. Это порядок, в котором вы привыкли о себе не думать. | рука откладывает телефон в сторону, пауза | поворот — честная оговорка, снимает стыд |
| 9 | Сохрани — присылай себе, когда снова скажешь одну из этих фраз. Готова начать не с понедельника, а сегодня? Напиши ТЕСТ. | экран телефона, в комментариях набрано «ТЕСТ» | финал, призыв и причина сохранить |

**Обложка:** «Пять фраз. Сколько — про вас?» — телефон с заголовком «Тест» на экране заметок.

**Подпись под пост:**
Пять фраз — простой тест, а не диагноз.
Если узнали себя в трёх и больше — это, скорее всего, не про вас лично, а про то, как вообще устроен день у большинства женщин рядом с вами.
Отправьте это той, кто точно скажет «это про меня». А если готовы начать сегодня — напишите ТЕСТ.

**Что сохранят:** чтобы прислать себе в момент, когда снова скажете одну из этих фраз.

### Разбор Психолога

| Блок | Рычаг | Сила |
| ---- | ----- | ---- |
| Хук | разрыв в знании, виден край | сильно |
| Про тебя | снимает порог, объясняет правила теста | сильно |
| Тело (5 фраз) | виден край, лёгкость чтения, узнавание | сильно |
| Поворот | честная оговорка — снимает стыд после теста | сильно |
| Финал | практическая польза, одно действие | сильно |
| Подпись | прямой репост-механизм («отправьте той, кто скажет „это про меня“») | сильно |

1. **Зачем досматривать?** Формат теста с номерами 1/5…5/5 физически тянет долистать до конца — иначе тест «не пройден».
2. **Зачем сохранять?** Названо вслух: как личное напоминание на будущее, в момент рецидива.
3. **Зачем пересылать?** Прямой призыв переслать конкретному человеку, который узнает себя — самый сильный из трёх репост-триггеров в этой подборке.
4. **Что человек сделает после?** Перешлёт карусель и/или напишет «ТЕСТ».

**Вердикт: сдавать.** Формат-тест — самостоятельный жанр карусели, ещё не использованный ни в одном из 10 готовых материалов клиента; хорошо ложится в правило «7–10 слайдов» (здесь 9, тело чуть длиннее из-за пяти пунктов теста, но каждый слайд — на 5–7 слов и читается мгновенно).
