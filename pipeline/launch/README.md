# Запуски

Здесь лежат планы запусков: прогревы, воронки, окна продаж.
Один запуск — один файл, имя `ГГГГ-<продукт>-<формат>.md`.

| Что | Где | Статус |

| **Формат 1** · прогрев в сторис → анкета → обзвон (10 + 4 дня) | `pipeline/launch/2026-полиглот-прогрев-сторис.md` | готово |
| **Формат 2** · воронка через рилс → лид-магнит → мини-курс → большой курс | — | следующий шаг |

**Порядок работы.** Сначала Формат 1 — он даёт деньги и, что важнее, базу.
Формат 2 строится на этой базе: все, кто заполнил анкету и не купил, плюс все,
кто пришёл в Telegram за 14 дней запуска, — это вход в воронку.
Поэтому Telegram-канал открывается в день 1 прогрева, а не после запуска.

**Чего не делать:** не строить обе ступени одновременно. Одна ступень доводится
до пика, и только потом берётся следующая. Иначе расфокус — и не взлетит ни одна.
