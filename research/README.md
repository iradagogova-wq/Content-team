# Разбор ниши

Сюда падает всё, что собрано и разобрано по нише. Отсюда сценаристы берут
темы, хуки и каркасы — не из головы.

## Что здесь лежит

| Файл | Кто пишет | Что внутри |
| ---- | --------- | ---------- |
| `<дата>-<ниша>-таблица.md` | Разведчик | 15–25 материалов, которые выстрелили за два месяца: ссылка, цифры, дословный хук, каркас |
| `<дата>-<ниша>-карта.md` | Стратег | формулы хуков, каркасы, форматная сетка, десять углов, переизбыток и дыры |

## Правила

- **Срок годности разбора — два месяца.** В короткой форме приёмы выгорают
  за квартал: то, что собирало сохранения в июне, в сентябре уже мозоль.
  Карта старше двух месяцев — повод прогнать `/niche` заново, а не поправить
  старую.
- **Старые разборы не удалять.** По ним видно, что в нише менялось: приём,
  который ушёл и вернулся, — это готовая тема.
- Каждый вывод в карте привязан к номеру строки таблицы. Вывод без номера
  в карту не попадает.
- Цифра, которую никто не видел своими глазами, помечается `не проверено`.
  Пустая клетка чинится за минуту, выдуманная не чинится никогда.

## Как обновить

```
/niche маркетинг для салонов красоты
```
