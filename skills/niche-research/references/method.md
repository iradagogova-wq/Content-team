# Метод разбора

## Что считается вирусным

**Не абсолютные просмотры.** Миллион у миллионника — это норма, а не результат.
Двадцать тысяч у автора с тремя тысячами подписчиков — выброс, и разбирать надо
именно его.

> Вирусное = материал, который выбился из **собственной нормы автора**
> минимум втрое.

Поэтому рядом с просмотрами всегда стоит размер автора. Без него цифра ничего
не значит.

## Таблица собранного

Минимум 15 строк, по всем форматам. Только рилсы — получится вывод о рилсах,
а не о нише.

| # | Ссылка | Автор и размер | Площадка | Формат | Дата | Просмотры | Сохранения и комментарии | Хук дословно | Каркас | Почему залетело | Откуда цифра |
| - | ------ | -------------- | -------- | ------ | ---- | --------- | ------------------------ | ------------ | ------ | --------------- | ------------ |

Три колонки, которые чаще всего портят:

- **Хук дословно** — копия первой фразы или текста обложки, слово в слово.
  Не пересказ: пересказ убивает то единственное, ради чего собиралась таблица.
- **Каркас** — устройство в 4–6 слов: «боль → своя ошибка → приём → оговорка».
- **Откуда цифра** — `видел на странице` / `со слов владельца` / `не проверено`.

После таблицы — срез по форматам:

| Формат | Сколько нашлось | Что с ними |
| ------ | --------------- | ---------- |
| Рилс | | |
| Карусель | | |
| Шортс | | |
| ТикТок | | |
| ИИ-мультфильм и ИИ-графика | | |

Строку про ИИ-формат заполняй честно. Нет таких материалов — пиши «не нашёл».
Натянутый тренд стоит владельцу недели работы.

## Карта ниши: восемь разделов

### 1. Что происходит в нише
Пять строк. Что изменилось за два месяца, чего стало больше, чего меньше.

### 2. Формулы хуков
7–10 формул. Каждая — шаблон плюс живой пример **из таблицы**.

> **Формула:** [конкретная цифра] + [неожиданное следствие]
> **Пример:** «Смета на 400 тысяч. Клиент пропал на этом слове» (4)
> **Работает потому что:** цифра обещает конкретику, следствие ломает ожидание

Формулы должны быть разные по природе: боль, цифра, чужая ошибка, запрет,
признание, спор, сцена, вопрос. Десять вариантов одного приёма — брак.

### 3. Каркасы, которые повторяются
3–5 структур с разметкой по секундам или слайдам.

| Каркас | Разметка | В каких строках | Под какой формат |
| ------ | -------- | --------------- | ---------------- |

### 4. Форматная сетка
Что в этой нише стоит делать — по данным таблицы, а не по общим представлениям
о площадках.

| Формат | Что показала таблица | Стоит ли | Почему |
| ------ | -------------------- | -------- | ------ |

Про ИИ-мультфильмы отвечай прямо: меньше трёх примеров — «в нише не прижилось,
начинать не с него». Это самый дорогой формат по времени.

### 5. Десять углов
| Тема | Угол | Чувство | Формат | Донор |
| ---- | ---- | ------- | ------ | ----- |

Общая тема — не тема. «5 советов по продуктивности» забракуй сам.

### 6. Чего в нише переизбыток
Приёмы, которые повторяют все. На них уже мозоль.

### 7. Дыры
Чего никто не делает, а спрос виден. Ищи в комментариях под собранными
материалами: повторяющийся вопрос под чужим роликом — готовая тема с
подтверждённым спросом.

### 8. Что забирать, а что нет
Забирается каркас: устройство, порядок блоков, место поворота.
Не забирается текст — он сработал в чужом голосе.

## Шаблон profile.md

```markdown
# Профиль: <ниша>

- **Кто говорит:**
- **Ниша:**
- **Для кого:**
- **Главная боль аудитории:**
- **Площадка и хронометраж:**
- **Что зритель должен сделать после:**

## Голос

- **Тон:**
- **Обращение:** ты / вы
- **Стоп-слова:**

### Эталонные куски
Два-три настоящих текста автора. Это главный ориентир — описания вроде
«пиши бодро» бесполезны, работают только примеры.
```

Поля заполняются по мере надобности, а не все сразу на входе.
