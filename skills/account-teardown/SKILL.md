# Разбор аккаунта

Тебе дают чужой аккаунт-ориентир, ты объясняешь, на чём он держится.

Разбор ниши отвечает на вопрос «что сейчас работает вообще». Этот отвечает на
другой: «почему работает именно у них». Разные ответы, и второй ближе к делу.

## Откуда берёшь материал

**Instagram и TikTok обычно не читаются автоматически** — закрыты логином, а
часто и сетевыми ограничениями. Проверь один раз; не открылось — работай с тем,
что прислал владелец: скриншоты, скопированный текст, цифры.

Прислали только ссылку — попроси материалы, не выдумывай содержимое. Пустой
разбор честнее правдоподобного. Минимум на аккаунт:

1. Скриншоты 5–8 самых залетевших материалов, с видимыми цифрами.
2. Скриншот обычного материала — **норма**, без неё выброс не посчитать.
3. Скриншоты комментариев под двумя-тремя — там боль своими словами.
4. Размер аккаунта и что он продаёт.

Прислали мало — скажи, чего не хватает, и разбирай то, что есть, пометив
объём выборки.

## Что отдаёшь: восемь частей

### 1 · Паспорт

| Поле | Значение |
| ---- | -------- |
| Аккаунт | |
| Площадка | |
| Размер | |
| Что продаёт | |
| Частота выхода | |
| Основной формат | |

Не видно — пиши `не видно`. Не достраивай.

### 2 · Что залетает

Не самые крупные цифры, а **выбросы относительно нормы этого аккаунта**.
Материал на 40 тысяч у автора, где обычно 8 тысяч, важнее материала на
100 тысяч у того, где обычно 90.

| Материал | Формат | Цифры | Во сколько раз выше нормы | Хук дословно | Каркас |
| -------- | ------ | ----- | ------------------------- | ------------ | ------ |

Норма не видна — так и пиши, и не делай выводов о выбросах. Без нормы цифра
не значит ничего.

### 3 · Что НЕ залетает

Половина ценности разбора. Провалы показывают границу: где у аудитории
пропадает интерес, какая тема не их, какой формат не идёт.

| Материал | Формат | Цифры | Гипотеза, почему не пошло |
| -------- | ------ | ----- | ------------------------- |

### 4 · Карта боли

Главная часть. Тут разбор либо даёт то, ради чего затевался, либо нет.

**Поверхностная боль — не боль.** «Не знаю, что снимать» — это симптом.
Под ним лежит другое: «боюсь снять и услышать, что я не эксперт». Первое
собирает лайки. Второе продаёт.

Для каждой боли — три слоя:

| Как говорят вслух | Что под этим | Чего на самом деле боятся |
| ----------------- | ------------ | ------------------------- |
| «нет времени на контент» | контент не окупается, жалко часов | «я вложусь и снова окажется, что это никому не нужно» |

Правила:

- **Формулировки дословные, их словами.** Твой пересказ боли — уже не боль,
  а твоё представление о ней.
- **Комментарии под их материалами — лучший источник.** Там аудитория
  формулирует боль сама, без фильтра. Повторяющийся вопрос в комментариях —
  готовая тема с подтверждённым спросом.
- **Не сочиняй третий слой.** Не видно, чего боятся, — пиши `не видно из
  материала`. Выдуманная глубинная боль звучит убедительно и уводит в сторону
  на месяц вперёд.

### 5 · Какие проблемы решают

| Уровень | Что здесь |
| ------- | --------- |
| С чем человек приходит | как он сам формулирует запрос |
| В чём проблема на самом деле | как её видит аккаунт |
| Что аккаунт обещает | результат его словами |
| Как обещает добиться | метод, если назван |

Разрыв между первой и второй строкой — это и есть их позиционирование.
Обычно там же лежит их лучший хук.

### 6 · Как продают

Где в контенте продажа и через что: призыв, воронка, продукт, цена если видна.
Отдельно — **как часто продают на фоне пользы**: соотношение важнее самих
продающих материалов.

### 7 · Фирменные приёмы

3–5 ходов, которые повторяются у них из материала в материал. То, по чему
их узнают.

### 8 · Что забрать, а что нет

- **Забрать** — три конкретные вещи: каркас, приём, угол.
- **Не трогать** — две: то, что работает только на их лице, размере или
  истории.

Копируется устройство. Не копируется голос: в чужом голосе приём разваливается.

## Когда аккаунтов несколько

Разбери каждый отдельно, потом сведи:

| | Что общего | Что различается |
| - | ---------- | --------------- |
| Боли | | |
| Каркасы | | |
| Форматы | | |
| Способ продажи | | |

**Общее у трёх и более аккаунтов — это закон ниши.** Встретилось у одного —
это его личный стиль, и повторять его чужому человеку незачем.
