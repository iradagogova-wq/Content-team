# Переносимые скилы

Три скила, которые превращают любую нишу в готовые сценарии для соцсетей.

Метод живёт в скиле, данные — в проекте. Один пакет обслуживает сколько угодно
ниш и клиентов.

## Установка

```bash
npx skills add iradagogova-wq/Content-team
```

Ставится в любой проект. Для Claude Code, Codex, Cursor и остальных
поддерживаемых агентов.

Это переносимая версия отдела: только метод, без моего профиля, ниши и голоса.
Внутри этого репозитория работает полный отдел (`.claude/agents/`,
`.claude/commands/`) — а `skills/` уезжает в чужие проекты.

## Что внутри

| Скил | Что делает |
| ---- | ---------- |
| `niche-research` | собирает вирусное за два месяца в таблицу и делает карту ниши: формулы хуков, каркасы, форматная сетка, десять углов |
| `account-teardown` | разбирает конкретные аккаунты-ориентиры: что у них залетает относительно их же нормы, какую глубинную боль трогают, что продают |
| `lead-magnet` | придумывает тему бесплатного материала под боль и кодовое слово, прогоняя идеи через тест «срочно надо» |
| `content-scenarios` | пишет сценарии по единому стандарту — карусели, рилсы, шортсы, тикток, ИИ-мультфильмы |
| `scenario-psychology` | правит готовый текст по рычагам влияния: находит блоки, которые ничего не делают |

Скилы работают вместе, но каждый самодостаточен: можно поставить один.

## Как пользоваться

Три фразы обычными словами — слэш-команды не нужны.

```
Разбери нишу: маркетинг для салонов красоты
```
Соберёт 15–25 материалов, покажет пять сильнейших и попросит добить ссылками
из твоих Рекомендаций. Дальше сделает карту ниши.

```
Разбери эти аккаунты — вот скриншоты
```
Достанет карту боли в три слоя: как говорят вслух → что под этим → чего боятся
на самом деле. Instagram и TikTok закрыты от чтения, поэтому работает по твоим
скриншотам, а не по ссылкам.

```
Сделай 5 каруселей про сметы
```
Возьмёт темы и формулы хуков из карты, напишет по стандарту. Больше трёх —
сначала покажет один целиком.

```
Прогони этот текст через психолога
```
Работает с чем угодно: свежий сценарий, старый пост, чужой материал для разбора.

## Что появится в проекте

```
content/
└── <ниша>/
    ├── profile.md                    ← кто говорит, для кого, каким голосом
    ├── research/
    │   ├── ГГГГ-ММ-ДД-таблица.md     ← что собрано, со ссылками и цифрами
    │   └── ГГГГ-ММ-ДД-карта.md       ← что из этого следует
    └── scripts/                      ← готовые сценарии
```

Разбор для салонов красоты не мешает разбору для юристов: у каждой ниши
своя папка и свой голос.

## Три правила, на которых всё держится

**Цифра, которую никто не видел своими глазами, помечается `не проверено`.**
Придуманная цифра опаснее её отсутствия: на ней построится карта, а на карте —
все сценарии. Пустая клетка чинится за минуту, выдуманная не чинится никогда.

**Каждый вывод в карте помечен номерами строк таблицы.** Вывод без номеров
вычёркивается. Это единственное, что отделяет разбор от гладкого текста,
который приятно читать и невозможно применить.

**Больше трёх сценариев — сначала один целиком, потом остальные.** Десять
сценариев, написанных молча, — это десять раз повторённая одна ошибка.

## Срок годности разбора

Два месяца. В короткой форме приёмы выгорают за квартал: то, что собирало
сохранения в июне, к сентябрю уже мозоль. Карта старше — повод прогнать разбор
заново, а не править старую.

## Чего скилы не делают

Не публикуют. Не выдумывают кейсы, цифры и отзывы автора. Не обещают
виральность: они дают устройство, которое уже сработало в этой нише, —
остальное решают тема, лицо и регулярность.
