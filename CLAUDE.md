## Правила отдела

1. Ничего не выдумывать про меня, мой опыт, цифры и кейсы. Нет данных —
   спросить или поставить `ЗАПОЛНИТЬ`.
2. Факты и статистику давать только с источником. Без источника не публикуем.
3. Любой текст сверять с `brand/voice.md` перед сдачей.
4. Прежде чем писать новое — заглянуть в `brand/swipe-file.md` и
   `results/performance.md`: что уже сработало, что провалилось.
5. Цифры каждого вышедшего материала заносить в `results/performance.md`.
6. Идеи и черновики держать в `pipeline/`, а не в переписке — чат забывается,
   файлы остаются.
7. Любой сценарий — карусель, рилс, шортс, тикток, ИИ-мультфильм — пишется по
   `brand/scenario-standard.md`. Один каркас на все форматы, меняется только
   форма подачи.
8. Темы и хуки берутся из свежей карты ниши в `research/`, а не из головы.
   Карты нет — сначала `/niche`, потом сценарии.
9. Ни один сценарий не показывается мне без прохода через Психолога. Он
   работает по `brand/psychology.md` и называет место, где текст не цепляет.
10. **Сначала всё, что можно узнать без меня.** Любой разбор начинается с
    открытых источников: доступность площадки, размер рынка, независимые
    подтверждения болей, живая речь аудитории из отзывов и жалоб. Просить у
    меня ссылки и скриншоты — последнее средство, а не первое. Работа,
    которая ждёт моих данных, не сделана.
11. Сначала лид-магнит, потом сценарии. Каждый сценарий пишется в одном из
    двух режимов: А — ведёт на кодовое слово, Б — нативная продажа без призыва.
    Мультфильмы и сериалы по умолчанию Б: призыв ломает историю.

## Структура отдела

```
content-team/
├── CLAUDE.md            ← этот файл: я, ниша, голос, правила
├── PLAYBOOK.md          ← порядок работы: от ниши до готовой карусели
├── .claude/
│   ├── agents/          ← четырнадцать сотрудников-субагентов
│   └── commands/        ← /niche, /account, /leadmagnet, /scenarios, /sharpen
├── brand/
│   ├── voice.md              ← как я говорю
│   ├── scenario-standard.md  ← правило сценария для любого формата
│   ├── psychology.md         ← рычаги: чем цепляет, продаёт и сохраняется
│   ├── lead-magnet.md        ← куда ведём и в каком из двух режимов
│   └── swipe-file.md         ← копилка сработавшего
├── research/            ← разбор ниши: таблица вирусного и карта ниши
├── pipeline/
│   ├── ideas.md         ← банк тем
│   ├── calendar.md      ← что и когда выходит
│   └── scripts/         ← готовые сценарии
├── results/
│   └── performance.md   ← каждый материал и его цифры
└── skills/              ← переносимая версия: ставится в любой чужой проект
```

Папка `skills/` — тот же метод без моего профиля, ниши и голоса. Ставится в
любой проект командой `npx skills add iradagogova-wq/Content-team` и работает с
любой нишей: разбор, сценарии, правка по рычагам. Внутри этого репозитория
работает полный отдел, наружу уезжает только метод.

## Коннекторы

Claude из коробки читает эту папку. Интернет, картинки и календарь подключаются
отдельными переходниками — в интерфейсе они называются MCP или коннекторы,
ставятся мышкой в настройках.

| Коннектор | Кому | Зачем |
| --------- | ---- | ----- |
| Поиск в интернете | Исследователю | тренды, чужие ролики, статьи, новости ниши |
| Файлы (уже есть) | всем | читать и писать темы, сценарии, цифры |
| Canva | Дизайнеру | обложки и картинки прямо из чата |
| Планировщик постов | Выпускающему | складывать готовое в очередь на публикацию |
| Таблицы / Notion | Аналитику | цифры по роликам в одной таблице, а не в скриншотах |

**Начать с двух: поиск в интернете и файлы.** Этого хватает, чтобы система
заработала целиком. Canva и планировщик — потом, когда конвейер уже крутится:
иначе первый вечер уйдёт на настройку переходников вместо роликов.
