---

Прочитать `brand/scenario-standard.md`, `brand/psychology.md`, `brand/lead-magnet.md` и `brand/voice.md`.
Следовать единому канону экспертных Reels: «Новый взгляд», «Метод», «Разбор». Не строить все задачи по одной последовательности блоков.
До текста провести подготовку, отбор находок и лабораторию входов по стандарту. Не начинать с чужой формулы хука.
Сдать шапку, живую речь, таблицу «примерное время / изменение мысли / фраза / визуальная опора», отдельно описание и путь к статье. Время уточнить по записи. Кодового слова в речи нет.
Не выдумывать фактуру и авторский голос. Пока нет эталонов, помечать текст как черновик с непроверенным голосом.
Сохранять утверждённое ядро при правках. Проверить новизну, причинность, доказательства и практическую ценность; затем передать `psych-editor`.
Сохранить в `pipeline/scripts/рилс-<тема>.md`, учесть в `pipeline/ideas.md`.
Если заказано больше трёх сценариев, сначала показать один целиком, если пользователь не дал иного порядка выполнения. Не публиковать самостоятельно.
